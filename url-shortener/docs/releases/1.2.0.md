## Residual risks

- **UTS #46 processing can have edge cases or behavior changes across library versions, potentially affecting less common internationalized hostnames.**: ICU4J 77.1 is pinned, and regression tests cover Unicode/Punycode equivalence, redirects, and prohibited destinations. Review the test suite before any IDNA-library upgrade.
- **Some underscore-host destinations may not resolve or be accepted consistently by external DNS providers or clients, even though the service is required to accept the specified form when destination rules permit it.**: Continue applying existing destination rules and verify resolution for destinations where required; do not broaden the URL-scheme policy.
- **A downgrade to the previous resolver could make links created during this release with Unicode hosts fail to redirect.**: Inventory links created during the release and retain or backport the IDN-capable resolver for them during rollback; avoid changing their stored original URLs.

## Rollback plan

No database migration needs to be reversed. If rollback is required, first stop creation of links that depend on the new host handling and inventory affected links. Deploy the previous application version while retaining or backporting the IDN-capable redirect-host conversion for links created during this release. Keep stored `original_url` values unchanged. Verify representative existing ASCII links and affected IDN links before restoring normal traffic; do not complete a full resolver downgrade if it would strand those links.
